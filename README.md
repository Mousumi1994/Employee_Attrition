# Employee Attrition Analysis

## Project Overview
This project focuses on analysing employee attrition to understand the factors that may influence employees to leave an organization. Using an employee attrition dataset, the analysis aims to identify workforce trends, explore attrition patterns, and generate meaningful insights that can help HR professionals make data-driven decisions.

## Project Objectives
- Analyse employee attrition patterns and workforce trends.
- Identify key factors associated with employee turnover.
- Explore employee demographics and job-related attributes.
- Present findings through an interactive-style analytical dashboard/report.
- Provide insights that can support employee retention and HR decision-making.

## Project Files
- `employee_attrition_dataset.xlsx` – Employee attrition dataset.
- `Attrition Dashboard.pdf` – Dashboard report presenting the analysis.

## Business Value
This project demonstrates how data analysis can help organizations understand employee turnover, identify potential retention challenges, and support better workforce planning.
